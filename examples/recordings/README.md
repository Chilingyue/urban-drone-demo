# 精选飞行记录

从本机有 `result.json` 的 26 轮 `city_300` 试验中选择两轮互补的成功记录。
两轮均完成送达、落地并解除武装，离线评估未发现机体包络侵入静态障碍。
这是精选演示，不是随机抽样，不能据此推导送达率。

| 完整运行目录 | 选择原因 | 任务用时 | 实际路径 | 最小外壳净空 | 恢复 / 全局重规划 | 原始文件合计 | 压缩包 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `20261118_133653_949261_city_300_0` | 较新的高效演示；7 次局部路径提交，包含越墙、侧绕与穿洞 | 265.438 s | 278.007 m | 0.300 m | 0 / 0 | 4.15 MiB，165 个文件 | [1.73 MiB](20261118_133653_949261_city_300_0.tar.gz) |
| `20261117_203650_676851_city_300_0` | 保留此前认可的第 5 个障碍穿洞过程，适合展示多种策略 | 349.230 s | 280.292 m | 0.599 m | 1 / 1 | 5.64 MiB，272 个文件 | [2.37 MiB](20261117_203650_676851_city_300_0.tar.gz) |

第一轮有 3 次 `execution_hold`，其中发生过制动距离与占用检查触发；第二轮有 1 次
`execution_hold` 和 1 次后撤恢复。因此它们是有代表性的成功记录，并非全程无暂停、无后撤。
第 5 个障碍在第一轮选择越过，在第二轮最终穿洞；策略由各轮观测与规划决定。

用时取自原始 `mission.elapsed`，包括任务启动、起飞和降落等阶段；路径长度与净空取自
原始 `result.json` 的离线评估。净空按半径 0.35 m 的机体球与静态障碍计算，排除地面，
不等于实机完整旋翼包络的安全认证。1 MiB = 1,048,576 字节。

## 包含哪些数据

压缩包逐文件保留原运行目录的全部现有内容：估计航迹、Gazebo 真值航迹、指令跟踪、
初始与局部规划、事件日志、观测点与规划地图快照、世界及先验/真值描述、评估结果、报告图、
PX4/MAVROS/Gazebo 等日志、SITL 参数、源码和模型快照，以及原始 `run_manifest.json`。
原始目录没有的视频、全量传感器 rosbag 或飞控 ULog 不额外生成；此处的“完整”指完整保存当轮已记录的文件。
真值仅用于离线评估，不供飞行规划读取。

`index.json` 记录原始字节数、压缩字节数、指标，以及每个文件的 SHA-256；
`SHA256SUMS` 记录压缩包的 SHA-256。两包合计 4,299,509 字节（4.10 MiB），
解压后的文件内容合计 10,268,760 字节（9.79 MiB）；文件系统实际占用可能略大。

## 解压并回放

在项目根目录执行校验：

```bash
(cd examples/recordings && sha256sum -c SHA256SUMS)
```

解压到 `runs/`，保留已有同名原始记录：

```bash
for recording in examples/recordings/*.tar.gz; do
  target="runs/$(basename "$recording" .tar.gz)"
  if [ ! -e "$target" ]; then
    tar -xzf "$recording"
  fi
done
```

分别回放，每次运行其中一条：

```bash
bash scripts/replay.sh runs/20261118_133653_949261_city_300_0
bash scripts/replay.sh runs/20261117_203650_676851_city_300_0
```

只校验数据和生成回放世界，不打开窗口、不启动飞行：

```bash
bash scripts/replay.sh runs/20261118_133653_949261_city_300_0 --prepare-only
bash scripts/replay.sh runs/20261117_203650_676851_city_300_0 --prepare-only
```

回放需要主 README 所列的仿真依赖；按估计航迹重现历史位置与策略，不重建完整姿态和动力学。
每轮 `source/` 和 `run_manifest.json` 保留当时版本及哈希。当前源码与较早那轮存在差异，
重新飞行也会受实时观测与时序影响，不能保证复现完全相同的蓝线。原始记录保持不变。
